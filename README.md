# osu! lazer 网页主菜单复刻

这是一个以前端学习为目的的非官方项目，参考 osu! lazer 客户端的主菜单，用 HTML、CSS 和 JavaScript 制作页面及部分交互。

## 使用方法

1. 在 [Releases](https://github.com/hghasegawa718-pixel/osu-lazer-web-ui/releases) 页面下载 **Source code (zip)** 并解压，或克隆本仓库。
2. 在解压后的文件夹中，用较新的桌面浏览器打开 `osu-menu.html`。
3. 开场结束后点击中间的 osu! Logo，展开菜单；点击“开始游玩”或“编辑”进入子菜单，再通过“返回”回到上一级。

无需安装依赖或运行构建命令。请保留文件夹结构，页面通过相对路径读取 `assets` 中的资源。

## 已实现

- 主菜单展开，以及游玩、编辑、多人子菜单的切换与返回。
- 菜单按钮的悬停扩宽、回弹、图标循环动画和点击高亮。
- 顶部四种游戏模式图标的选中切换与白色指示条移动。
- 开场、Logo 周围白条和退出动画视频，以及背景音乐、悬停和点击音效。

## 当前范围与限制

- 本项目主要展示主菜单及部分交互，不包含进入谱面后的实际游玩；部分按钮目前仅供展示。
- 有声自动播放受浏览器设置影响：如果浏览器阻止了背景音乐，当前版本不会在点击 Logo 后自动重试。可在浏览器中允许自动播放后刷新页面。
- 开场视频与独立背景音轨可能存在时间偏差；动画和音效尚未逐项与原客户端完全校对。
- 部分 CSS 动画使用较新的浏览器特性，旧版本浏览器的表现可能不同。

## 项目结构

```text
osu-menu.html             页面结构和资源入口
main.js                   菜单、模式切换及音视频交互
base.css                  全局样式和变量
menu.css                  主菜单按钮与 Logo 样式
layout-support.css        场景、菜单和视频布局
interaction-support.css   按钮交互效果和动画
sidebar.css               顶部栏布局与样式
assets/                   图片、音频和视频资源
```
